2.1 The Human Mortality Database release

All analyses use the period life tables of the Human Mortality Database (HMD). The HMD is revised continually — new years are added and past estimates are sometimes corrected — so “the HMD” is not a fixed data set. To make the analysis reproducible we therefore pin one specific release: the bulk download (“all statistics” zip archive) dated 29 October 2026.

The HMD licenses its estimates (life tables, death rates, exposures) under CC BY 4.0, but asks users to obtain the data from its website rather than from third parties. This repository therefore does not contain the data. You download the zip yourself (a free registration is required) and save it, unopened and unrenamed apart from the name below, as

raw/hmd/hmd_statistics_20261029.zip

The file raw/MANIFEST.json — which is part of the repository — records the release, where it came from, and SHA-256 checksums of the zip and of the four files inside it that the analysis reads. A checksum is a 64-character fingerprint of a file’s exact bytes: if a single byte differs, the fingerprint differs. Verifying it proves that you are running the analysis on exactly the data the paper used.

2.3 Verifying the release

mdmx.data.verify_release() locates the release and recomputes every checksum. It accepts either the zip exactly as downloaded or — for convenience — a folder raw/hmd/20261029/ holding just the four files with their paths as inside the zip. In both cases each of the four files must match the manifest, and if the zip is present its own checksum must match too. Any mismatch stops the pipeline with an error.

Verify the checksums and register the release as the root artefact 
report = data.verify_release(P.data.hmd_release)
print(f"Release found at: {report['source']}")
if report["zip_sha256"]:
    print(f"Zip checksum     : OK ({report['zip_sha256'][:16]}…)")
for member, res in report["members"].items():
    print(f"  {member:<45s} {'OK' if res['ok'] else 'MISMATCH'}")

# Record the verified release as the root of the provenance graph.  Its
# content is the release label and the checksums of the four member files —
# deliberately NOT the file location or the zip's own checksum, so that the
# cache is identical whether the data were read from the zip or from an
# extracted folder, on any computer.  Every downstream artefact is thereby
# tied to exactly these bytes.
artifacts.save(
    "hmd_release",
    {"release": P.data.hmd_release,
     "members": {m: r["sha256"] for m, r in report["members"].items()}},
    params={"release": P.data.hmd_release},
    desc="Verified HMD bulk release: checksums of the four files used",
)

2.4 The populations

The HMD covers 50 populations in this release. Several are not independent: the United Kingdom total (GBR_NP) contains England & Wales, Scotland and Northern Ireland; Germany (DEUTNP) contains East and West Germany for the years they overlap; and New Zealand (NZL_NP) contains its Māori and non-Māori populations. The HMD also publishes civilian-only series for France and England & Wales, which omit military deaths in war years. The register below records these relationships; it lives in config/populations.csv, so it can be read and edited without touching code.
