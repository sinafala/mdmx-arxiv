4.1 The rules

A life table enters the analysis only if it passes all of the following checks. Each rule removes a whole country-year — both sexes — because the tensor needs a female and a male table for every country-year it holds. The rules are applied in order, and each removed country-year is recorded with the first rule that removed it.

  1. Excluded populations. The civilian-only series FRACNP and GBRCENW (chapter d1).
  2. Missing values. A table with any missing \(m_x\), \(q_x\) or \(a_x\).
  3. Flat old-age tail. A table whose \(q_x\) is identical at ages 105 and 109. When the underlying data are too thin to estimate mortality at the oldest ages, the HMD’s old-age model can return the same value across the whole tail; such a tail carries no age information. The rule looks only at two high ages because ties at younger ages are common and harmless: the HMD publishes \(q_x\) to five decimals, so two adjacent ages with \(q_x \approx 0.0001\) often have the same value.
  4. Sex pairing. Both sexes must be present.
  5. Age range. Ages above 109 (the open interval 110+, where \(q_x = 1\) by definition) are dropped from every table.

The thresholds are parameters in config/params.toml ([data] section).

## The rules

A life table enters the analysis only if it passes all of the following
checks.  Each rule removes a whole **country-year** — both sexes — because
the tensor needs a female and a male table for every country-year it holds.
The rules are applied in order, and each removed country-year is recorded
with the *first* rule that removed it.

1. **Excluded populations.**  The civilian-only series FRACNP and GBRCENW
   (chapter d1).
2. **Missing values.**  A table with any missing $m_x$, $q_x$ or $a_x$.
3. **Flat old-age tail.**  A table whose $q_x$ is *identical* at ages
   `{python} P.data.flat_tail_ages[0]` and `{python} P.data.flat_tail_ages[1]`.  When the
   underlying data are too thin to estimate mortality at the oldest ages, the
   HMD's old-age model can return the same value across the whole tail; such
   a tail carries no age information.  The rule looks only at two high ages
   because ties at younger ages are common and harmless: the HMD publishes
   $q_x$ to five decimals, so two adjacent ages with $q_x \approx 0.0001$
   often have the same value.
4. **Sex pairing.**  Both sexes must be present.
5. **Age range.**  Ages above `{python} P.data.age_max` (the open interval 110+, where
   $q_x = 1$ by definition) are dropped from every table.

The thresholds are parameters in `config/params.toml` (`[data]` section).

### The flat tails

The figure shows the four flagged tables (heavy lines) against the same
population's tables in the five years either side (thin lines).  From
about age 80 the flagged tables stop rising with age, while their neighbours keep
rising.

```{python}
#| label: fig-s1-flat-spots
#| fig-cap: "The life tables removed for a flat old-age tail (q_x identical at ages 105 and 109; heavy lines) and the same population's tables in the five years before and after (thin grey lines), ages 70–109, both sexes."
flat = excl_data[excl_data["rule"] == "flat old-age tail"]
fig, axes = plt.subplots(1, len(flat), figsize=(2.6 * len(flat), 3.2), sharey=True)
axes = np.atleast_1d(axes)
for ax, (pop, year) in zip(axes, flat[["pop", "year"]].itertuples(index=False)):
    for sex in data.SEXES:
        near = lt_raw[(lt_raw["pop"] == pop) & (lt_raw["sex"] == sex)
                      & lt_raw["year"].between(year - 5, year + 5) & (lt_raw["year"] != year)
                      & lt_raw["age"].between(70, P.data.age_max)]
        for _, g in near.groupby("year"):
            ax.semilogy(g["age"], g["qx"], color="#bbbbbb", lw=0.6)
        this = lt_raw[(lt_raw["pop"] == pop) & (lt_raw["sex"] == sex) & (lt_raw["year"] == year)
                      & lt_raw["age"].between(70, P.data.age_max)]
        ax.semilogy(this["age"], this["qx"], color=plotting.COLORS[sex], lw=2,
                    label=sex.title())
    ax.set_title(f"{names[pop]} {year}", fontsize=9)
    ax.set_xlabel("Age")
axes[0].set_ylabel(r"$q_x$ (log scale)")
axes[0].legend(fontsize=7)
plotting.save_figure(fig, "fig-s1-flat-spots")
```
