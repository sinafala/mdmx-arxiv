# Snapshots

Each snapshot of this repository is the companion of one version of the article on arXiv.  It is a
git tag, whose files never change once the version is announced, and a folder of the rendered
book on this repository's GitHub Pages site.  The article's links to the code name the tag, and
its links to the book name the folder, so every version of the article keeps its own companion.

| Tag | Article | Rendered book | Data | Status |
|---|---|---|---|---|
| [`arxiv-v3`](https://github.com/sinafala/mdmx-arxiv/tree/arxiv-v3) | [arXiv:2603.20518v3](https://arxiv.org/abs/2603.20518v3) | [book](https://sinafala.github.io/mdmx-arxiv/arxiv-v3/) | HMD 20261029 | draft |

*draft*: the arXiv version is not yet announced, and the snapshot may still be replaced.
*frozen*: announced; the tag and the book's folder are never changed.

This snapshot (`arxiv-v3`) was exported from commit `356ae5099e58` of the
author's development repository.
